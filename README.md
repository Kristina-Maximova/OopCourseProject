# Job Overview

## Приложение для сбора и обработки данных по вакансиям

Поиск вакансий проводится на платформе [HeadHunter](https://hh.ru/vacancy)

Есть возможность обработки полученных данных:

- сортировка и фильтрация по размеру зарплаты
- сортировка и фильтрация по дате создания
-

Данные о вакансиях заносятся в базу,
на данный момент запись производится в json-файл

## Для использования

Клонируйте репозиторий [GitHub](https://github.com/Kristina-Maximova/OopCourseProject)

Установите необходимые зависимости:
python = "^3.13"
requests = "^2.32.3"

## Пример использования приложения:

```commandline
Введите поисковый запрос: вакансия
Рады будем помочь в поиске работы вашей мечты!
Введите ключевые слова для фильтрации вакансий: Python
Введите количество вакансий для вывода в топ N: 3
Начиная с какой даты ищем вакансии?
Введите дату в формате ДД.MM.ГГ: 01.01.03
Всего найдено вакансий: 61
После обработки осталось вакансий: 61
-----------------------------------------------------------------------------------------------------------------------
36: Backend-разработчик (Python) с опытом во Frontend (React), зарплата 300000, url: https://api.hh.ru/vacancies/117342329?host=hh.ru.
56: Fullstack developer (Python), зарплата 300000, url: https://api.hh.ru/vacancies/117468876?host=hh.ru.
38: Data Engineer Python + Spark / Инженер по обработке данных, зарплата 280000, url: https://api.hh.ru/vacancies/107663270?host=hh.ru.
работает add_vacancies, в списке 8
-----------------------------------------------------------------------------------------------------------------------
Вакансии из топ списка внесены в базу
```

vac1 = Vacancy(**{'name': 'Middle Backend Developer (Python FastAPI + SQL)',
                      'salary': 210000,

                      'created_at': '2025-02-21T14:46:49+0300',
                      'url': 'https://api.hh.ru/vacancies/117570423?host=hh.ru',
